# DTC-TRUS GitHub Project Page

Static GitHub Pages project page for the DTC-TRUS manuscript:

**Distilling Temporal Coherence into 2D Networks for Transrectal Ultrasound Prostate Video Segmentation**

This package keeps the existing project-page format and applies only the release-link update for the public TRUS-V dataset. The official paper URL is still pending.

## Current links

- Code: `https://github.com/DYDevelop/DTC-TRUS`
- Dataset: `https://khdp.net/database/data-search-detail/TRUS-V`
- Paper: pending official publication URL
